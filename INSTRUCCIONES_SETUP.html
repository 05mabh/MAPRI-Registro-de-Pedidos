PARTE 1 — Conectar con Google Sheets

Los pedidos que el vendedor guarda en la app se sincronizan automáticamente a un Google Sheet cuando tiene internet.

1 Crear el Google Sheet

1. Abre Google Drive → + Nuevo → Google Sheets

2. Nómbralo: MAPRI — Registro de Pedidos

3. Déjalo en blanco — el script crea las columnas automáticamente

2 Pegar el script en Apps Script

1. En el Sheet: menú Extensiones → Apps Script

2. Selecciona todo (Ctrl+A) y borra el código que aparece

3. Abre mapri_google_apps_script.gs con el Bloc de Notas, copia todo y pega

4. Guarda con Ctrl+S

3 Publicar como Web App

1. Botón Deploy → New deployment

2. Configura exactamente así:

  • Type: Web App
  • Execute as: Me
  • Who has access: Anyone

3. Clic Deploy → autoriza permisos → copia la URL generada

https://script.google.com/macros/s/AKfycb.../exec
⚠️ Guarda esa URL — la necesitas en el siguiente paso.

4 Pegar la URL en la app

1. Abre mapri_app_vendedores.html con Bloc de Notas

2. Busca con Ctrl+F:

let WEBAPP_URL = '';

3. Reemplaza por:

let WEBAPP_URL = 'https://script.google.com/macros/s/AKfycb.../exec';

4. Guarda (Ctrl+S)

✓ La app ya está conectada a Google Sheets.

PARTE 2 — Publicar como App instalable (GitHub Pages + PWA)

Esto convierte la app en una dirección web permanente. El vendedor la abre una vez en su celular y la instala como app — sin Play Store, sin App Store, completamente gratis.

5 Crear cuenta en GitHub

1. Ve a github.com y crea una cuenta gratuita (si ya tienes, salta este paso)

2. Confirma tu email

⚠️ El nombre de usuario que elijas aparecerá en la URL de la app. Elige algo como mapri-gt o el nombre del cliente.

6 Crear el repositorio

1. En GitHub, clic en + → New repository

2. Nombre: mapri-app

3. Marca Public (obligatorio para GitHub Pages gratis)

4. Clic Create repository

7 Subir todos los archivos

1. En el repositorio recién creado, clic en uploading an existing file (o "Add file → Upload files")

2. Arrastra todos estos archivos de la carpeta MAPRI_USB:

  • mapri_app_vendedores.html
  • manifest.json
  • sw.js
  • icon-192.png
  • icon-512.png
  • icon-180.png

3. Escribe un mensaje como: "App inicial MAPRI v3.2"

4. Clic Commit changes

8 Activar GitHub Pages

1. En el repositorio: clic en Settings (engranaje arriba a la derecha)

2. En el menú izquierdo: clic en Pages

3. En "Branch": selecciona main → carpeta / (root)

4. Clic Save

5. Espera 1-2 minutos → aparecerá la URL:

https://tu-usuario.github.io/mapri-app/mapri_app_vendedores.html
✓ ¡Esa es la URL que le das a los vendedores!

PARTE 3 — Instalar en el celular del vendedor

Una vez publicada la URL, el vendedor la instala en 30 segundos. Queda como ícono en la pantalla de inicio — igual que cualquier app.

9 Android (Chrome)

1. El vendedor abre Chrome y entra a la URL de la app

2. Chrome muestra automáticamente un banner: "Agregar MAPRI a pantalla de inicio"

3. Si no aparece: menú de Chrome (⋮) → Agregar a pantalla de inicio

4. Confirmar → el ícono naranja de MAPRI aparece en la pantalla del celular

5. La próxima vez, el vendedor abre la app directo desde ese ícono — sin necesidad de internet

10 iPhone / iPad (Safari)

1. El vendedor abre Safari (no Chrome) y entra a la URL

2. Toca el botón de compartir ⬆️ (abajo al centro)

3. Desplaza y toca "Añadir a pantalla de inicio"

4. Confirma → el ícono de MAPRI aparece en el inicio
